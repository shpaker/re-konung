# Реализация на Rust

Рабочее пространство Cargo использует edition 2024. Rust реализует игру;
Python и Tiled остаются независимыми эталонными инструментами. При расхождении
форматов прав Python. Обязанности крейтов и зависимости описывает
[архитектура](../../../ARCHITECTURE.md).

| Тема | Содержание |
|---|---|
| [Данные и сцены](data-scene.md) | Загрузка, границы парсеров, графика, порядок отрисовки, группы частей, кадры и стоимость позы |
| [Перемещение](movement.md) | Сетка, занятость клеток, маршруты, тики, события, перестроение пути и стоимость движка |
| [Симуляция](simulation.md) | Правила существ, размещение, текущее состояние, модели времени и света, стоимость распределения характеристик |
| [Рендеринг](rendering.md) | Спрайты, текстуры, анимация, узлы существ, глубина, камера и граница освещения |
| [Просмотрщик](viewer.md) | Состояние инструмента, воспроизведение, диагностика и замеры полного окна |
| [Игра и интерфейс](player-ui.md) | Поток приложения, настройки, механизмы дизайн-системы и контракты новой игры |

Команды находятся в [сборке](../building.md) и [проверках](../testing.md).
Использование — в руководствах [игры](../../guides/player.md) и
[просмотрщика](../../guides/viewer.md). Основания игровых правил —
в [исследованиях K1](../../research/k1/README.md).
