# Rust-реализация

Cargo-workspace в `crates/` (edition 2024). Повторяет Python-пакет `konung/` слой за слоем; Python — эталон, и при расхождении прав Python (AGENTS.md). Пока Rust ничего не заменяет: Python-CLI и расширение Tiled остаются как есть.

## Крейты

| Крейт | Что внутри | Статус |
|---|---|---|
| `k1-data` | данные игры K1: репозиторий (`repo`) и формат карты (`map`) | `Konung.N` и `LIGHTS.N`: разбор и побайтно точная запись, тесты на `original/` |

Будущие крейты: `k2-data`, `engine` (игровая логика), `cli`. Общее ядро выделяется, только когда появится второй конкретный потребитель, — та же логика, что в [games.md](games.md) про проверку общности движка на K2.

## Слои `k1-data`

```
данные игры (original/k1/<издание>/game)
  → repo: GameDir — поиск файлов без учёта регистра, номера карт, чтение байтов; FileSet (игра/обучение)
    → map: чистые parse(&[u8]) / serialize — KonungMap, Lights; ФС не трогают
      → {игровые данные, Tiled} — слои выше появятся позже
```

Тестируемость: форматный слой тестируется подменой данных, а не реализаций; `GameDir` dyn-совместим (методы `&self`, конкретные типы возврата). Трейты для моков объявляет потребитель, когда они ему действительно понадобятся («accept traits, return structs»); провайдерских трейтов в `k1-data` нет.

## Проверки

`crates/` проверяются и локально, и в CI (job `rust` в `.github/workflows/ci.yml`: fmt, clippy, тесты).

```bash
just cargo-test   # тесты: синтетические всегда, на данных — если есть original/
just cargo-lint   # cargo fmt --check + clippy -D warnings
```

Запись (`serialize`, `serialize_lights`) проверяет точную геометрию сеток до записи, а не только итоговый размер: строки 81 и 79 клеток дают верное число байтов, но сместили бы границы строк. Та же проверка добавляется в Python-эталон отдельным PR — реализации расходятся только в строгости проверки некорректных входных данных, на валидных картах они идентичны побайтно.

Тесты на данных (`crates/k1-data/tests/original.rs`) повторяют `tests/k1/test_maps.py` в части карты: parse → serialize побайтно для всех `Konung.N` обоих изданий, `Tutorial.4/5` (ENG), всех `LIGHTS.N`/`TLIGHTS.N`. Без `original/` они пропускаются (ранний return с сообщением); как его получить — [k1/editions.md](k1/editions.md).

Проверка записи из AGENTS.md для Rust та же: все файлы обоих изданий после «прочитать → записать» совпадают с оригиналом побайтно. Проверка «единственная сырая декорация в слоте 994» пока только в Python: она требует `GRAPH.RES`, который в Rust ещё не перенесён.
