# Карты первой части в Tiled

Расширение `tiled/konung/` открывает оригинальные `Konung.N` прямо в Tiled, только для чтения. Сохранить можно в обычный формат Tiled (.tmx/.tmj).

## Установка

```bash
just tiled-install
```

Расширение копируется в папку расширений Tiled (`%LOCALAPPDATA%\Tiled\extensions\konung` на Windows), и запущенный Tiled подхватывает его сам. После этого «Файл → Открыть» → `original/k1/<издание>/game/Konung.N`. `GRAPH.RES` и `Objects.res` расширение ищет в той же папке. Первая карта открывается несколько секунд: столько занимает декодирование `GRAPH.RES`, дальше оно берётся из кэша.

Tiled выбирает скриптовый формат по суффиксу `.<расширение>`, а у карт Князя расширение — номер. Поэтому расширение регистрирует форматы «Князь, карта 1» … «Князь, карта 50». Открыть через него `LIGHTS.N` или `Game.N` не выйдет — будет ошибка размера.

## Как карта ложится на Tiled

| Tiled | Значение |
|---|---|
| Ориентация | staggered, ось Y, сдвинуты нечётные строки |
| Размер | 80 × 160, тайл 116 × 64 (шаг 116 по x и 32 по строке; ромб 114 × 64 рисуется от левого нижнего угла клетки и совпадает с игрой) |
| Тайлсет `graph` | коллекция картинок, номер тайла = слот `GRAPH.RES`; выравнивание объектов — top-left |
| Слой `ground` | основной тайловый слой |
| Слой `overlay` | верхний тайловый слой |
| Слой `decorations` | тайл-объекты: декорации карты в порядке слотов (свойства `slot`, `unknown`). В начале слоя — 4 клетки тайловых слоёв с тайлом не 114×64 (свойства `cellLayer`, `cellX`, `cellY`): Tiled поставил бы их от нижнего края, а игра — от верхнего |
| Тайлсет `shadows`, слой `shadows` | тени объектов: чёрная маска, прозрачность слоя 0.4 |
| Тайлсет `objects`, слой `objects` | объекты: картинка кадра, позиция = позиция в игре + смещение кадра. Свойства: `objectId`, `slot`, `cellX`, `cellY`, `flags`, `frame`, `frameTime`, `flames`, `unknown`. Порядок — по нижнему краю, как в игре |

Проходимость и свет пока не выводятся: у них сетка вдвое мельче, и способ показа ещё не выбран (отдельная карта, слой-картинка или объекты).

## Сверка с эталоном

Рендер Tiled совпадает с `konung k1 map`: на карте 1 максимальная разница — 2 единицы яркости (округление при смешивании теней). Как снять полноразмерный рендер в Tiled — [../agents.md](../agents.md).
