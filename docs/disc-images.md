# Образы дисков MDS/MDF

Образ своего диска снимается в Alcohol 120%: `*.mds` — описание дорожек, `*.mdf` — сырые секторы. 7-Zip такой MDF не открывает, поэтому дорожки достаёт `konung disc` (`konung/disc.py`).

```bash
uv run konung disc original/k1/rus/image/konung.mds original/k1/rus/disc
```

Получается `track01.iso` (данные, открывается 7-Zip) и `track02.wav`…`trackNN.wav` (CD-аудио: 44100 Гц, 16 бит, стерео).

## MDS

Всё little-endian. Сведения взяты из открытых описаний формата (libmirage) и проверены на двух изданиях (RUS и ENG).

| Смещение | Тип | Смысл |
|---|---|---|
| 0x00 | 16 байт | `MEDIA DESCRIPTOR` |
| 0x50 | u32 | смещение блока первой сессии |

Блок сессии (24 байта): +10 — u8, число записей дорожек (с служебными); +20 — u32, смещение таблицы дорожек.

Запись дорожки (80 байт):

| Смещение | Тип | Смысл |
|---|---|---|
| +0 | u8 | режим: младшие 4 бита 9 — аудио, A — Mode 1, C — Mode 2 Form 1; старшие биты у разных программ разные (`0xAA` и `0xEC`) |
| +4 | u8 | номер дорожки; 0xA0–0xA2 — служебные записи TOC |
| +0x0C | u32 | смещение доп. блока: u32 pregap, u32 длина в секторах |
| +0x10 | u16 | размер сектора в MDF: 2352, или 2448 с субканалами |
| +0x24 | u32 | первый сектор |
| +0x28 | u64 | смещение дорожки в MDF |

Данные в сыром секторе: Mode 1 — с 16-го байта, Mode 2 Form 1 — с 24-го, по 2048 байт.

## Проверенные издания

| | RUS | ENG |
|---|---|---|
| Сектор | 2352 | 2448 (с субканалами) |
| Дата-трек | Mode 1, 212352 сектора | Mode 2 Form 1 (CD-XA), 162388 секторов |
| Аудио | 10 дорожек | 10 дорожек |
