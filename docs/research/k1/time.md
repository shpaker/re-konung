# Игровое время

Счётчик, цикл и пороги подтверждены нашим побайтовым чтением RUS, ENG
и EXE обучения. Арифметика цвета и переключатели — в [освещении](lighting.md),
реализация — в [симуляции](../../development/rust/simulation.md#time-and-lighting-contracts), сам тик — в [перемещении](movement.md).

<a id="sources-and-markers"></a>

## Источники и отметки

**Подтверждено** означает нашу проверку байтов своей копии (оба издания
и обучение) либо рендер. Дополнительные ссылки на read-only клон закреплены
на [`cf5a332`](https://github.com/Marisa-Chan/Slavik/tree/cf5a3320dc93859e3dc51f37ee823fed30f399b6). **По Slavik** — только источник, не наш установленный факт.
Код не копируется; факты пересказываются со ссылками. При расхождении
реконструкции (например, float-деления клона) с оригиналом прав оригинал.

Читались `original/k1/rus/game/konung.res`, `original/k1/eng/game/KONUNG.EXE`,
`original/k1/eng/game/TUTORIAL.EXE`. Смещения файловые, VA берётся
из PE-секций каждой сборки: Watcom BEGTEXT `0x410000`, DGROUP `0x450000`.
Каждый адрес прочитан в своей сборке, не перенесён автоматически.
The lighting routines have matching control flow and constants, with per-build
operands; they are not byte-identical. The complete packed traces agree under the
[documented emulation assumptions](lighting.md#original-evidence-and-reproduction).
Глобальные `0x81xxxx`/`0x82xxxx` находятся в .bss: образ их не содержит,
начальный ноль не доказывает ненулевые настройки, которые пишутся при выполнении.

## Подтверждено собственным чтением игры

<a id="the-day-counter-and-the-length-of-a-cycle"></a>

### Суточный счётчик и длина цикла

Счётчик один, время внутри суток — его остаток:

| Факт | Доказательство |
|---|---|
| Один глобальный int32 по `VA 0x81D640`, одинаково во всех сборках | Чтение в начале световой функции: RUS `0x193FB` / `VA 0x428FFB`; также инкременты, обнуление, сериализация и проверки |
| 21600 — **делитель** счётчика | `mov ebx, 0x5460`, знаковый idiv; сохраняется только остаток в локальном `[ebp-4]`, отдельного глобального остатка нет; RUS `0x193F6` / `VA 0x428FF6` |
| Это общий рабочий тик, не только часы | Два инкремента, запись/чтение, обнуление; `test byte [0x81D640], 0xF` по RUS `0xD456` / `VA 0x41D056` запускает проход 200 итераций раз в 16 тиков; `(counter & mask) == mask` по `0x2B2D` / `VA 0x41272D`. У клона вне света — условие тайника и чередование двух кадров (**по Slavik**, [`game.cpp:861`](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game.cpp#L861), [`game.cpp:1554`](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game.cpp#L1554)) |
| Два инкремента не зависят от опций света | `inc dword [0x81D640]`, `ff05 40d68100`: RUS `0x26AE5` / `VA 0x4366E5`, `0x26B19` / `VA 0x436719`; ENG `0x26D29`/`0x26D5D`; обучение `0x26C39`/`0x26C6D`. Ровно два в каждой сборке. Второй в цикле по скорости `[0x81D634]`; ветвления на опции нет |
| Суточный бросок выбирает одну из двух ночных палитр | Сразу после modulo: call rand, mov ebx,100, знаковый idiv, cmp edx,`0x5A` (90). При остатке 0 вероятность 90/100, результат нормализуется в `[ebp-0xC]` и пишется `[0x81D608]`: RUS `0x1943F` / `VA 0x42903F`. Других записей нет; чтения только окна 9–11: RUS `0x19722`/`0x1978C`/`0x197BA`, ENG/обучение `0x1989A`/`0x19904`/`0x19932`. Это вычисляемый `_bLightEff`, не настройка; [глобальные света](lighting.md#the-four-globals-separated) |
| Активация карты обнуляет счётчик | `mov [0x81D640], esi(=0)`, esi из обнулённого `[0x81D710]`; функция очищает `[0x81cf80]` (0x38 байт), `[0x81a814]` (0x28), копирует 64 dword карты (`rep movsd`, `ecx=0x40`, `edi=[0x81D45C]`) и задаёт базу текущей карты. RUS `0x281EB` / `VA 0x437DEB`, ENG `0x28434` / `VA 0x438034`, обучение `0x2781E` / `VA 0x43781E`. Подтверждён контекст, но не точные моменты вызова: вход через jump table, число прямых caller не доказательно |
| Четырёхбайтный счётчик проходит парный сериализатор полей | Адрес и push 4 передаются помощникам записи/чтения: RUS `0x14BB7` / `VA 0x4247B7` → `0x43EE9E`, `0x15061` / `VA 0x424C61` → `0x43F186`; ENG/обучение `0x14CDB` / `VA 0x4248DB`, `0x15185` / `VA 0x424D85`; помощники сдвинуты (ENG `0x43F0EE`). Индексируется `[0x831C80 + idx·4]`, вызывается потоковый ввод/вывод. Отдельная функция по категории копирует счётчик в `+0x3FC`, `+0x400`, `+0x404` записи через `[0x81D580]`: RUS `0x2488A`/`0x248BA`/`0x248EA`, ENG/обучение `0x24ABA`/`0x24AEA`/`0x24B1A`; условия — `[rec+0x3DA]`, `[rec+0x3E2]`, `[rec+0x3EA]`. Назначение именно загрузкой/записью сохранения остаётся выводом ниже |

21600 тиков по 60 мс — 21,6 минуты **при скорости 0**. Уровень скорости
добавляет проход счётчика на кадр: цикл `21600 / (1 + speed)` кадров
по 60 мс. Предел 0..5 — **по Slavik**, game.h:64,1487, [`game_play.cpp:122-133`](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game_play.cpp#L122-L133), [`game_input.cpp:183-190`](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game_input.cpp#L183-L190);
два инкремента и граница цикла прочитаны нами, предел 5 — только клоном.

<a id="the-phase-boundaries"></a>

### Границы фаз

Тринадцать строго возрастающих **знаковых int16**, одинаковых во всех EXE:

```
0, 1800, 1830, 3570, 3600, 5400, 8100, 11700, 11880, 11910, 16155, 16200, 18900
```

| Сборка | Смещение массива | VA |
|---|---|---|
| RUS konung.res | `0x4100E` | `0x45AE0E` |
| ENG KONUNG.EXE | `0x42246` | `0x45AE46` |
| ENG TUTORIAL.EXE | `0x41652` | `0x45AE52` |

Клон хранит те же числа как int32 ([`game_data.cpp:25`](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game_data.cpp#L25)); это его представление,
не тип исходной таблицы. Привязка доказана чтениями из световой функции:
сравнения выбирают ветви [таблицы света](lighting.md#what-a-phase-does-to-the-picture), там же константы переходов.
Условия перехода включительные: RUS `0x198C2` / `VA 0x4294C2`,
`cmp …, 0x78 / jle` в окне 13. При t=120 формула ещё выполняется
и даёт плато; отдельная ветка плато начинается с 121. Это условие прочитано
побайтно; одинаковое устройство остальных — вывод, согласующийся
с `<25`, `<61`, `<101`, `<121` клона.

<a id="a-unit-of-1440-ticks"></a>

### Единица 1440 тиков

В обоих изданиях есть знаковое деление разности счётчиков на 1440:
RUS `0x21C76`, ENG `0x21EA6`, `mov ebx, 0x5A0`, idiv.
Это совпадает с деревенскими таймерами **по Slavik** ([`game_quest.cpp:711`](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game_quest.cpp#L711)).
21600/1440=15: это не час 24-часового дня. Смысл единицы неизвестен,
на выводы здесь не влияет.

<a id="what-the-source-gives-intervals-not-day-phases"></a>

## Источник даёт интервалы, а не названия времени суток

[Таблица освещения](lighting.md#what-a-phase-does-to-the-picture) задаёт 13 окон, тройку ambient и признак света земли.
Из неё следуют интервалы:

| Интервал | Часть цикла | Свойство |
|---|---|---|
| Светлый | 19021 → 5400 через 0 | Ambient нейтрален `(0,0,0)`, кроме тёплой полосы; тайлового света нет |
| Тёплая полоса | 1800 → 3600 | Внутри светлого: положительные красный/зелёный дают тёплый оттенок |
| Тёмный | 5400 → 19021 | Ветки затемнения, плавный переход на концах |
| Тайловый свет | 8100 → 18900 | Строго внутри тёмного интервала, вычисляется свет тайлов |

Картинка начинает темнеть с ветки 5400, за три часа нашего условного циферблата
до тайлового света, который выключается в 18900 ещё во время обратного перехода.
Тёмный интервал длиннее: 13 621 тик против 7 979, не две равные половины.
Это **границы ветвей**. Из-за целочисленных половин **значения** меняются
на один-два тика иначе: тепло с 1802, нейтраль снова с 3593 и 19020,
ещё внутри переходов окон 4/13. Выбор границ для потребителя —
в [контрактах времени](../../development/rust/simulation.md#time-and-lighting-contracts).

<a id="phases-of-the-day-are-our-vocabulary--unknown"></a>

### Названия времени суток — наша терминология, исходная неизвестна

Ни оригинальная цепочка сравнений, ни клон не называют фазы.
Есть только `_lightPhazes`, `_bLightGround`, `_bLightEff` ([`game.cpp:1762-1893`](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game.cpp#L1762-L1893)),
без утра, полудня, вечера, сумерек, ночи, рассвета. Другие чтения счётчика
в клоне тоже не дают названий.

- Подтверждён **интервал** `tick % 21600`, тройка ambient и флаг света земли.
- day/dusk/night/dawn — наши слова; соответствие окнам обозначается условным.
- Последовательность day → dusk → night → dawn не является подтверждённым
  свойством цикла: нейтраль возвращается трижды (1, хвост 4 + 5, хвост 13),
  тёплая полоса внутри светлого. Тест/UI проверяет интервалы — двенадцать
  порогов, длины переходов на краях тёмного и тайловый свет, не четыре названия.

<a id="hypotheses-and-unknowns"></a>

## Гипотезы и неизвестное

- Начало новой игры в нуле: [Slavik game.cpp:2426](https://github.com/Marisa-Chan/Slavik/blob/cf5a3320dc93859e3dc51f37ee823fed30f399b6/game.cpp#L2426) обнуляет счётчик, но наш найденный
  RUS 0x281EB / VA 0x437DEB — активация карты; точные caller/моменты неизвестны.
- Время в сохранениях: парный четырёхбайтный сериализатор и три категорийных
  поля подтверждены, назначение именно сохранением — вывод; save-код клона не называет его.
- 1440 может быть единицей деревенских дел, но не часом 24-часового циферблата.
- Названия фаз/часов неизвестны; ночное поведение обычных NPC K1 тоже
  остаётся неизвестным в [сравнении](../comparison.md#requires-verification).
- Глобальные пороги обходятся картами постоянного света; прочие переопределения
  карты не исключены. Сброс активации может взаимодействовать с загрузкой
  сохранения, моменты диспетчеризации неизвестны.

<a id="deliberate-runtime-differences"></a>

## Намеренные отличия выполнения

Наш день следует тику симуляции: 21600 × 60 мс = 21,6 минуты,
без исходного множителя проходов кадра. Будущий игровой переход должен
сохранять время сессии; новая карта просмотрщика — независимая сцена
с новой симуляцией. HH:MM и слова фаз условные, не восстановленные правила.
Подробности — [контракты времени](../../development/rust/simulation.md#time-and-lighting-contracts) и [часы просмотрщика](../../development/rust/viewer.md#the-hour-we-display--our-convention-not-a-fact-about-k1).
