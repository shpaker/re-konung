# Исследование существ

Персонажи, монстры и жители K1: подтверждённые факты, сведения по источнику,
гипотезы и неизвестное. Раскладка записей — в [Game.N](../formats/game-state.md),
графика — в [GRAPH.RES](../formats/graph-res.md) и [OBJECTS.RES](../formats/objects-res.md).

| Тема | Содержание |
|---|---|
| [Анимация](animation.md) | Состояния, кадры, маска пропуска, два смысла состояния 4 |
| [Поведение](behavior.md) | Приказы, состояние отряда, мирные решения, имена и неизвестные правила |
| [Размещение](placement.md) | Появление на карте, отказы загрузки и достижение целей |
| [Бой](combat.md) | Реакция на удар, смерть, ближний бой, здоровье, замеры и пределы уверенности |

Основной внешний источник — read-only Slavik, ссылки закреплены на
[`cf5a332`](https://github.com/Marisa-Chan/Slavik/tree/cf5a3320dc93859e3dc51f37ee823fed30f399b6).
**По Slavik** означает только чтение источника; **подтверждено** требует нашей
проверки файла, исполняемого кода или изображения. Гипотезы и неизвестное
отмечаются явно. Код без лицензии не копируется.

Решения реализации и их стоимость — в [симуляции](../../../development/rust/simulation.md)
и [рендеринге](../../../development/rust/rendering.md). Краткие намеренные
отличия остаются рядом с фактами оригинала.
