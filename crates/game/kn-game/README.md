# kn-game

Общий фасад, модель сцены и симуляция без Bevy.

- `game`: Game::open/root/maps, каталог, ресурсы, ошибки и идентификаторы карт.
- `new_game`: выбор героя, профили конструктора и предпросмотр; `session`: выбор состояния и создание симуляции.
- `scene`: модель сцены, текстуры и преобразование поз; `check`: безоконная проверка и отчёты.
- `visual_assets`: готовые маски света, мелкая сетка освещения и RGBA портретов; LIGHTS.RES повторно читается с типизированными ошибками.
- `lighting_params`, `game_time` и `CYCLE_TICKS` предоставляют модели K1 без прямой зависимости фронтендов от неё.
- `lib.rs` объявляет модули и сохраняет публичный API фасада.
- Scene/Piece/TextureId/Animation/PieceGroup несут данные отображения без типов фронтенда.
- Геометрия и движение доступны потребителям напрямую через kn-isometric и kn-movement.
- `session::Simulation` явно передаёт операции конкретной симуляции K1 и переводит команды/снимки журнала. Формат replay и сериализуемые DTO принадлежат фасаду.
- Движок перемещения не выбирает цель; восстановленное поведение и адаптер применения решений находятся в k1-game.

Подробности: [тематическая документация](../../../docs/development/rust/README.md).
Проверки: `just cargo-test`, `just cargo-lint`. Чистая логика не требует окна/GPU;
проверки на игровых данных используют локальный original/ и пропускаются без него.
