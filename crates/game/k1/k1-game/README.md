# k1-game

Ресурсы K1, сборка сцены и восстановленные правила без Bevy.

- `resources` загружает ресурсы; `presentation::scene/textures/lighting` собирают сцены, декодируют RGBA и рассчитывают классическое освещение.
- `rules` содержит поведение, бой, размещение, новую игру и время; `creatures` и `creature_anim` хранят состав и состояния существ.
- `simulation` исполняет правила и движение; runtime-операции акторов и снимки не зависят от сериализации журнала фасада.
- Основная граница потребителей — kn-game; текущие прямые адаптеры фронтендов перечислены в архитектуре. Адаптер `rules::movement` связывает правила с kn-movement; `geometry` задаёт размеры сетки K1.

Подробности: [тематическая документация](../../../../docs/development/rust/simulation.md).
Проверки: `just cargo-test`, `just cargo-lint`. Чистая логика не требует окна/GPU;
проверки на игровых данных используют локальный original/ и пропускаются без него.
