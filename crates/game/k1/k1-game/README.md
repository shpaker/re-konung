# k1-game

Ресурсы K1, сборка сцены и восстановленные правила без Bevy.

- resources/textures предоставляют графику и декодирование RGBA; scene строит упорядоченный список отрисовки.
- creatures, placement, rules и creature_anim хранят специфику игры.
- new_game, time_of_day и lighting предоставляют чистые операции правил и моделей.
- Основная граница потребителей — kn-game; текущие прямые адаптеры фронтендов перечислены в архитектуре. Этот крейт не импортирует общий движок.

Подробности: [тематическая документация](../../../../docs/development/rust/simulation.md).
Проверки: `just cargo-test`, `just cargo-lint`. Чистая логика не требует окна/GPU;
проверки на игровых данных используют локальный original/ и пропускаются без него.
