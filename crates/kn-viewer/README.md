# kn-viewer

Просмотрщик карт «Князя»: бинарь `re-konung-viewer`. Окно с картой, панель
выбора карты и отладочных оверлеев, headless-диагностика.

## Запуск

```bash
re-konung-viewer --game-dir <каталог игры> [--map N] [--source game|tutorial]
re-konung-viewer --game-dir <каталог игры> check --map 1
re-konung-viewer --game-dir <каталог игры> check --all [--format text|json]
```

Каталог игры — содержимое `inst/setup.dat`; как его получить,
[docs/k1/editions.md](../../docs/k1/editions.md).

Из репозитория без установки:

```bash
cargo run --release --manifest-path crates/Cargo.toml -p kn-viewer -- \
    --game-dir original/k1/rus/game
```

## Устройство

- `cli` — аргументы; `check` — подкоманда, которая не открывает окно и не
  требует GPU.
- состояние просмотрщика (`Viewer`) отделено от интерфейса: обработчики
  виджетов правят только состояние и оставляют `Rebuild` с причиной — `Map`
  (перестроить и навести камеру заново) или `Overlays` (перестроить, кадр не
  трогать), а сцену собирает одна система `rebuild_scene`.
- интерфейс — Bevy Feathers (тёмная тема): список карт, четыре переключателя
  оверлеев (проходимость, свет, маркеры `Game.N`, персонажи — включены по
  умолчанию), подпись с диагностикой (кусков, текстур, миллисекунды, масштаб,
  fps). Подписи на английском: у встроенного шрифта Feathers нет гарантии
  кириллицы. `Checkbox` сам не пишет `Checked`, поэтому обработчик
  синхронизирует его вручную — иначе каждый клик присылал бы `true`.
- `check` печатает отчёт по картам (текст или JSON) и возвращает ненулевой
  код, если карта не собралась или её текстура не декодировалась — так
  сцену проверяют CI и агенты без окна.
