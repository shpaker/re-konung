# kn-fe-player

Игровой фронтенд Bevy: сборка приложения, экраны, пользовательские действия
и жизненный цикл сеанса над kn-app.

- `PlayerConfig` передаёт открытую игру, настройки и начальный экран.
- `flow` исполняет эффекты приложения, `session` создаёт и удаляет сеанс.
- `screens` и `orders` отображают интерфейс и передают приказы через kn-game.
- Данные света и портретов приходят готовыми из kn-game; общие адаптеры света находятся в kn-render.

Подробности: [игра и интерфейс](../../../../docs/development/rust/player-ui.md).
Проверки: `cargo test --manifest-path crates/Cargo.toml -p kn-fe-player`;
тесты с игровыми данными используют локальный original/.
