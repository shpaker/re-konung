# kn-ui

Общая система интерфейса Bevy для игры и просмотрщика.

- palette/spacing/typo задают параметры дизайна и комплектный PT Sans: кириллица/латиница, лицензия assets/fonts/OFL.txt.
- KonungUiPlugin применяет тему Feathers и нормализацию шрифта; widgets собирает элементы управления.
- sync_checked отражает состояние флажков; pointer_over_ui проверяет значение Hovered.
- Панели, состояние виджетов, привязки, рендеринг и игровые правила принадлежат соответствующим потребителям.

Подробности: [тематическая документация](../../../../docs/development/rust/player-ui.md).
Проверки: `just cargo-test`, `just cargo-lint`. Чистая логика не требует окна/GPU;
проверки на игровых данных используют локальный original/ и пропускаются без него.

Интерактивный каталог компонентов: `just ui-showcase`, статически связанный пример.
