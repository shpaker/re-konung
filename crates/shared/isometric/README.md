# kn-isometric

Общая геометрия сдвинутой изометрической сетки без зависимостей от K1 и Bevy.

- `grid`: Cell, Direction, Grid, соседство и координаты решётки.
- `projection`: центры клеток, смещения пикселей и обратное преобразование
  с округлением половинок к чётному.
- Размеры игровых карт задаёт потребитель; стоимость пути определяет движение.

Публичный API — `src/lib.rs`. Проверки: `cargo test --manifest-path crates/Cargo.toml -p kn-isometric`.
Договорённости и сравнение с K1 описаны в [перемещении](../../../docs/development/rust/movement.md).
