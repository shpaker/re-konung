# kn-exec

Исполняемый файл игры «Князь» — бинарь `re-konung`.

## Запуск

```bash
re-konung --game-dir <каталог игры>
```

Каталог игры — содержимое `inst/setup.dat`; как его получить,
[docs/k1/editions.md](../../docs/k1/editions.md).

## Что сейчас

Заготовка: открывается стартовая карта новой игры первого найденного героя
(`Game.N` → `start_map`) тем же конвейером, что и в просмотрщике —
[`kn-game`](../kn-game) строит сцену, [`kn-io`](../kn-io) рисует её и
управляет камерой. Карта выглядит как в игре: отряд на месте, но отладочных
слоёв (проходимость, свет, маркеры) нет.

Игрового процесса нет: NPC, бой, квесты, переходы между картами и сохранение
появятся позже. От `kn-viewer` отличается назначением, а не рендерингом.

## Проверки

Бинарь тонкий — логика живёт в `kn-game` и `kn-io` и проверяется там:

```bash
just cargo-test
just cargo-lint
```
